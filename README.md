# lab-report · 实验报告编写

面向中文实验报告和课程理论报告的 AI skill。依据课程要求、模板、代码与真实运行材料编写、补全、检查和合并报告，重点保证内容、代码、截图与结论相互对应。

## 适用场景

- 根据课程模板、课件、配套代码和截图完成可编辑报告。
- 对照作业要求补齐思考题、结果分析和总结。
- 保留用户手动修订，只修改指定内容或代码格式。
- 合并多份报告，统一层级、编号和交叉引用。

普通技术问答不会自动扩展为报告制作；只审查或先讨论时，按相应范围处理。

## 使用方式

下载或克隆本仓库后，将其中的 lab-report 子目录整体放入所用 AI 工具支持的技能目录，保留 SKILL.md、agents 和 references 的相对位置。仓库根目录的 README.md 无需安装。各工具的发现路径、调用方法和能力不同，以其自身配置为准。

支持 Codex 技能调用的环境中，可使用：

```text
使用 $lab-report，根据指定模板、配套代码和截图完成报告。
保留原始材料，将成果保存到我指定的输出目录。
```

也可以要求检查：

```text
使用 $lab-report，对照课程要求检查当前报告，只列问题，暂不修改。
```

提供课程要求、模板、参考稿、源码、运行材料及输出位置；没有的材料直接说明即可。默认风格可被课程要求或用户指示覆盖。

## 工作约定

- 先读材料，区分原有代码、按实验要求修改和自主新增代码。
- 使用真实证据，缺项单独反馈，保留用户手改与原始材料。
- 正文直接写结果、解释和适用范围，避免防御性、免责式措辞。
- 默认只提交报告；作业要求源码或打包时按其要求执行。
- 报告中的代码默认进行语法高亮，无需额外提醒，使用 [CodeInWord](https://www.codeinword.com/)；明确要求不高亮时跳过，指定其他工具或格式时遵从指定。
- Word 交付保持可编辑，实际渲染并逐页检查排版。

## 所需能力

本 skill 提供指令与示例，不自带执行工具，也不自动安装依赖。

- 读取与编辑文件；生成 Word 时需要可用的文档处理工具。
- 核对运行结果时需要对应语言环境，或用户提供的真实运行材料。
- 使用 CodeInWord 时需要浏览器访问；无法访问时说明并协商替代方式。
- 检查 Word 排版时需要文档渲染工具；Windows 可在适用环境中使用独立 Word 实例导出 PDF 后查看页面。

代码上传、依赖安装、训练及外部操作遵从当前任务授权，不因使用 skill 自动取得额外权限。

## 个人资料

技能不包含个人身份值或私人资料路径。确需填写身份字段时，使用用户本次提供的信息或其已配置的本地资料入口，仅读取当前任务需要的字段。无需配置身份资料也可使用本技能完成其他报告工作。
