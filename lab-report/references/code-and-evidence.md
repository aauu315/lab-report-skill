# 代码与实验证据

## 代码范围、来源与呈现

1. 先确认每一处要求“完整代码”还是“核心代码”。完整代码须包含所需导入、入口和调用，不能只贴孤立函数；核心代码保留关键算法及理解所需上下文，不把所有依赖和界面样板塞进正文。
2. 需要多个独立完整程序时，按用户约定每处单独保存。常用约定为 code/lab<报告序号>_<程序序号>.<语言后缀>，不是所有任务的强制命名。
3. 检查原始 notebook、脚本与修改版的实际差异；为每个关键代码块注明作用及归属。原有但用于解释实验的必要代码仍可纳入，不能只展示新增代码。
4. 可用“代码2-1 原始数据加载”“代码2-2 训练循环（按实验要求修改）”“代码2-3 指标统计（自主新增）”这类标题表达归属。编号规则在报告中可理解，章节间不重号，叙述能找到对应代码；不能只在聊天中解释。
5. 使用用户现有隔离环境。安装依赖、上传代码、切换账号及长时间训练遵守本次授权，不从历史任务继承外部操作权限，也不因云端额度不足自行改为本地安装。
6. 编写或排版报告时，所有纳入报告的代码默认进行语法高亮，按语言选择正确模式，完整程序、核心代码与代码片段均适用；不等待用户提出“高亮”或“格式优化”。默认使用 CodeInWord：https://www.codeinword.com/，不必再次询问网址。用户明确要求不高亮时不处理；用户或作业指定其他工具、网站或格式时遵从指定。实际取得网站高亮结果，不上传无关材料；回填为可编辑代码文本，逐字核对字符、缩进及完整性。不能以代码截图代替可编辑代码，除非明确允许。网站不可用或代码不适合提交给外部服务时，说明具体限制并让用户选择手工处理或其他方式；不默默替换方法。默认高亮属于报告制作流程，不扩展仅审查、不修改、只改指定内容的任务范围，也不要求为普通代码问答或独立源码修改额外使用网站。
7. 只改代码格式时，不改语义、正文或图片；从当前文件取文本，核对报告代码与对应源码，以及非目标内容保持情况。

## 截图筛选与归档

- 日期、文件名和修改时间仅用于缩小范围；读图中的命令、输入、输出、窗口与状态后才确定归属。QQ 转存、下载和补充截图可能有不同命名或时间。
- 一图能证明多个小任务时可合并说明，不必强行拆图。一张开始画面或最后结果不能自动证明中间所有操作；演示有明显跳步时补必要状态。
- 原图保留，裁剪/标注存派生副本；保留命令与关键结果，不裁掉错误、权限限制、时间等会影响解读的内容。截图不含鼠标指针。
- 需要现场运行截图时，实际运行并截取界面；可保存的计算图直接输出清晰图片，但不把它冒称操作截图，不用绘制的终端画面假冒真实运行。
- 将选用图按实验归档，并在工作记录中映射原图、任务与正文图号。Word 内嵌图片，避免依赖外部链接。报告内已有裁剪图不表示原始截图可以删除。
- 缺证据时指出具体任务、缺什么、执行什么命令/点击什么、截图需包含什么；不要求重做已有充分证据的步骤。补充时统计的数据注明补充时点，不写成历史值。
- 若截图有权限不足导致的部分统计、某一步失败或方法差异，如实解释能证明的范围，不把可读取空间当全部目录大小，也不把计划写成成功。
- 用户自行运行截图时，提供可复制运行方式、一组确定输入、预期结果与截图位置；报告预留相应位置。其回传截图到位后核对真实结果，再定稿已完成的结果描述。

## 结果分析的判断

- 数字、包名、进程数、日志记录和实验条件从当前证据摘取；无法辨识时不猜。不要只贴图而遗漏作业要求的正文回答。
- 对算法进行与任务相称的正确性验证；测试数据、源码与报告结果对应。验证记录可放工作区，默认不把“通过数千次自动查询”等工程验证话语塞进课程报告。
- 明确原始实现与改动的作用和局限。训练轮数更多或 loss 更低不意味着所有评价指标、翻译样例或生成质量更好；检查失败案例，不为好看更换结论。
- 比较模型或 checkpoint 时使用相同测试集、预处理和指标定义，写清采样/样本数、轮次及指标方向。微小差值只描述观察结果，不在没有重复实验时宣称稳定提升或确定原因。
- GPU额度、换账号、环境故障等，只有实际发生且影响实验过程时才简要写入；账号地址等个人信息无必要不写。

## 条件示例：手写灰度直方图

仅当作业明确要求自行实现统计时使用这些限制：
- 自己遍历像素并统计 256 个灰度频次，不用 hist、histogram、bincount、calcHist 代替核心统计；绘图库可用于画已算出的频次。
- 检查输入是否彩色、是否已转灰度、像素类型和范围。频次之和应等于参与统计的像素数，并检查边界值。
- uint8 加法的溢出与截断应结合实际像素范围说明；实际图像没有溢出时不能声称它已经展示溢出，可另用明确标注的验证样例。
- 实验配套图像未指定唯一一张时，按彩色/灰度、前景背景等任务条件选图，说明实际选择。换图后重跑并同步修改分析。
